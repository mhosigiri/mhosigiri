## Recent projects

### DialEvac | November 2026

HackUTD team prototype for coordinating evacuations. The incident console brings together a hazard area, household outreach, triage, and a proposed fleet plan. Voice and SMS interactions capture needs such as mobility assistance. The routing workflow uses street graphs and vehicle constraints to generate routes for responders. Anish contributed to dispatcher and driver workflows, dispatch routing, and outreach safeguards. The stack includes TypeScript, SpacetimeDB, Photon, ElevenLabs, OSMnx, and OR-Tools. [GitHub repository](https://github.com/mhosigiri/DialEvac)

### Forecasting harmful algal bloom risk | Fall 2026

Biointerphase project in the Break Through Tech AI Studio. The team combined NOAA cell counts, water and weather observations, and satellite chlorophyll to study next-week red tide risk near Sarasota. The team produced a regional weekly table and a site-week table covering 136 sampling sites. It used splits by forecast year to evaluate features on later periods. Anish handled data exploration, visualization, and project coordination. [Team repository](https://github.com/Break-Through-Tech/Biointerphase-1B-forecasting-harmful-algal-bloom-risk)

### Tell Me More | October 2026

HackTX team project that starts with a photo of a family object and prompts a relative to tell its story. A FastAPI service uses Meta Muse to analyze the object, guide the interview, and draft a story. Story claims link to timestamped original audio, photo observations, or research. Supabase syncs new contributions and a Three.js view can present immersive memories. Anish contributed to the family graph, media retrieval, and end-to-end testing. [GitHub repository](https://github.com/mhosigiri/Tell-Me-More) · [HackTX submission](https://devpost.com/software/tell-me-again)

### Tollgate | October 2026

Private Python project for researching automated order execution. It separates market signal collection, strategy, risk approval, and order submission. Deterministic checks, an independent order audit, and broker reconciliation guard execution. A SQLite ledger and a read-only trace support review.

### Routine | September 2026

Private single-user planning app built with SwiftUI and FastAPI. The first build establishes the iOS client, authentication, PostgreSQL migrations, and a typed API contract. Scheduling and personal integrations are part of the project's planned expansion.

### XPense | September 2026

HackRice team project for learning financial habits with sandbox bank data, spending visualizations, and paper trading. A weekly heatmap shows spending patterns. Deterministic calculations produce the results that a Gemini assistant explains. Anish contributed to authentication, sign-up error handling, and the 3D opening. The project uses Next.js, Supabase, PostgreSQL, Gemini, Capital One Nessie, and Alpaca. [HackRice submission](https://devpost.com/software/xpense-86hqbx)

### DocExtract | August 2026

Local-first mortgage document extraction application. Combines native PDF parsing with OCR for scans, then links labels to values using page geometry. It normalizes common mortgage fields and returns confidence, bounding boxes, and page evidence so a reviewer can check the output. Uses FastAPI, React, OpenCV, PP-OCR, and Tesseract. [GitHub repository](https://github.com/mhosigiri/DocExtract)

### IT Support Handbook | June to July 2026

A troubleshooting reference for IT interns, with guides for network access, Windows device resets, Microsoft Company Portal synchronization, display setup, and contacts. Anish contributed the documentation structure and reset troubleshooting steps. [GitHub repository](https://github.com/mhosigiri/IT_Support)

### InterviewDuo | April to July 2026

Private web and iOS project for technical interview practice. It covers algorithms, object-oriented programming, databases, system design, and frontend development. The project uses adaptive practice and spaced repetition with a React frontend, a SwiftUI client, a FastAPI backend, and Supabase.

### HerdSignal | April 2026

HackSMU team project that separates elephant vocalizations from field recordings. The FastAPI backend uses NumPy, SciPy, and librosa to build spectrograms and apply non-negative matrix factorization. The Next.js frontend pairs the reconstructed signals with an interactive conservation map backed by PostGIS. Anish contributed to the frontend, deployment work, and upload metadata tracking. [GitHub repository](https://github.com/mhosigiri/HerdSignal) · [HackSMU submission](https://devpost.com/software/herdsignal)
